# Task routing

| Situation | Read first | Next authority |
| --- | --- | --- |
| Story planning | Feature, Contexts, Story acceptance | Story Card |
| Task readiness | Story, Task, dependency Results | Task Contract |
| Task execution | current Contract and required knowledge | Task Result |
| Material change | Story and affected future Tasks | plan revision/replan |
| Blocker or supersession | active artifact and decisions | human decision record |
