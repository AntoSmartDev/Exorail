# Schema 0.2 templates

Use `EPIC.md`, `FEATURE.md`, `STORY.md`, and `TASK.md` for canonical value
artifacts. Add `CONTRACT.md` only for a required exceptional Task boundary and
`RESULT.md` when a Task completes. Contexts, Milestones, Adapter Profiles,
minimal Execution Runs, consequential External Actions, and the provider-neutral
Team catalogue have dedicated forms. Projections are generated; do not manually
author them. Runtime-local binding, checkpoint and
event data have no template because they are deliberately outside the schema.
